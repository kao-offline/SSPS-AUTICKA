## Login incident

Production Vercel's Convex URL contained a trailing newline. The deployed frontend was an old build, and production Convex lacked JWKS, so issued tokens could not authenticate data requests. The URL was corrected, JWKS derived from the existing private key without replacing it, and backend/frontend deployed. Admin access was recreated with a random password.

Login now waits for verified authentication/profile state, normalizes usernames, reports pending/disabled accounts, and ends loading reliably. Historical Scrypt accounts remain supported alongside bcrypt accounts. Admin/self username changes synchronize password-provider identifiers and reject collisions.
